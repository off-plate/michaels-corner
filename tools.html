Considered, not built

Three that got planned and then cut. The reason is written down so the same idea does not come back next month.

  • CUT/01Automation ROI calculator. The should-you-automate scorecard already answers the same question. Payback framing lives in its fine print. Built later only if demand shows up.
  • CUT/02Meeting-prep prompt builder. Rarer than hard emails for a solo operator. The difficult-email builder covers the same translation pain with more reach.
  • CUT/03Model picker quiz. Model names change monthly. A stale pick kills trust faster than no tool. The cost calculator teaches the same judgment without naming a model.

What has to be true before I build one

  • It answers a question you would otherwise guess at.
  • It runs entirely in your browser, with no key and no account.
  • The math is visible. You can argue with it.
  • It does not go stale the week a model is renamed.
